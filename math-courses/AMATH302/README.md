# AMATH302 kit

Template kit for the AMATH302 (Introduction to Optimization) booklet. It is the AMATH301
companion booklet's design (`../../AMATH301/01-companion-booklet`) with a new colour palette and
an empty chapter (`ch-template.tex`) to copy once per lecture.

- `PROMPT.md`: paste into a new chat with the AMATH302 slides, this kit and the AMATH301
  companion PDF to generate the full booklet.
- `template-preview.pdf`: what the empty kit looks like.

Build: `pdflatex main.tex` three times.
